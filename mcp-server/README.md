# timetable-mcp

MCP server that wraps the S2-05 timetable admin API. Attach it to Claude Desktop or Claude Code and ask the agent to update the timetable from a screenshot, slide, or pasted text.

## Prerequisites

- Node.js 18+
- A bearer API token (see [Token setup in AGENTS.md](../AGENTS.md#1-generate-an-api-token))

## Install

```bash
cd mcp-server
npm install
```

## Environment variables

| Variable | Description |
|---|---|
| `TIMETABLE_API_URL` | Base URL, e.g. `https://timetable.edmundlim.systems` (no trailing slash) |
| `TIMETABLE_API_TOKEN` | Bearer token generated by `node scripts/generate-token.js` |

## Claude Desktop config

Add to `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "timetable": {
      "command": "node",
      "args": ["/absolute/path/to/timetable/mcp-server/server.js"],
      "env": {
        "TIMETABLE_API_URL": "https://timetable.edmundlim.systems",
        "TIMETABLE_API_TOKEN": "your-raw-token-here"
      }
    }
  }
}
```

Restart Claude Desktop after saving.

## Claude Code config (`.mcp.json` in repo root)

```json
{
  "mcpServers": {
    "timetable": {
      "command": "node",
      "args": ["./mcp-server/server.js"],
      "env": {
        "TIMETABLE_API_URL": "https://timetable.edmundlim.systems",
        "TIMETABLE_API_TOKEN": "your-raw-token-here"
      }
    }
  }
}
```

> **Note:** `.mcp.json` is gitignored in this repo because it contains the raw token. Create it locally only.

## Tools

| Tool | What it does |
|---|---|
| `get_timetable` | Fetch the full timetable, exams, announcements, custom subjects |
| `list_custom_subjects` | Return just the custom subjects array |
| `add_custom_subject` | Add a new custom subject type; validates key, colour, abbrev |
| `set_week` | Replace all 5 days of one week (odd or even); leaves the other week untouched |
| `save_timetable` | Advanced: POST a full payload directly (escape hatch) |
